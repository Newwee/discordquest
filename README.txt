========================================================================
                 DISCORD QUEST AUTO v2.3.0 - INSTALLER
========================================================================
GitHub Repository: https://github.com/Newwee/discordquest

โปรแกรมช่วยทำ Discord Quests อัตโนมัติ (Safe Mode • No AutoClaim)
พร้อมระบบคำนวณ Discord Orbs รวม, สลับบัญชี และระบบอัปเดตอัตโนมัติ

[ คุณสมบัติเด่น ]
• รันเควสต์ดูวิดีโอ (WATCH_VIDEO) 100% อัตโนมัติ ไม่ต้องเปิดแช่คลิป
• ไม่ต้องดาวน์โหลดหรือติดตั้งเกมขนาดใหญ่
• ปลอดภัย 100% ด้วย Safe Mode ไม่มีการกดรับของรางวัลอัตโนมัติ เพื่อเลี่ยง Captcha และการตรวจจับ
• คำนวณยอด Discord Orbs รวมแบบเรียลไทม์ พร้อม Rate-Limit Shield ป้องกัน 429
• ระบบสแกนหา Token ในเครื่องอัตโนมัติ (Local DPAPI Decryption)
• ระบบบันทึกประวัติบัญชี & สลับไอดี (Account History & Switcher)
• ระบบตรวจสอบและแจ้งเตือนอัปเดตอัตโนมัติจาก GitHub (Newwee/discordquest)
• คู่มือการใช้งานแบบโต้ตอบ (Interactive User Guide) แนะนำวิธีใช้ตั้งแต่เริ่มต้น
• หน้าต่าง WebApp สไตล์ ReactBits รองรับทุกขนาดหน้าจอ (1:1, 16:9, 4:3, Mobile)

[ วิธีการติดตั้ง ]
1. ดับเบิ้ลคลิกไฟล์ "Setup.exe"
2. เลือกโฟลเดอร์ปลายทางที่ต้องการติดตั้ง (หรือใช้ค่าเริ่มต้น)
3. ติ๊กเครื่องหมายถูกที่ช่อง "[x] ข้าพเจ้าได้อ่าน เข้าใจ และยอมรับข้อตกลง..."
4. กดปุ่ม "Install" เพื่อเริ่มการติดตั้ง
5. เมื่อติดตั้งเสร็จ สามารถกด "Launch Now" หรือค้นหา "Discord Quest Auto" ใน Start Menu หรือ Desktop ได้ทันที!

[ ความต้องการของระบบ ]
• Windows 10 / Windows 11 (64-bit)
• มี Node.js ติดตั้งอยู่ในเครื่อง (ถ้ายังไม่มี โหลดได้ฟรีที่ https://nodejs.org)
• เว็บบราวเซอร์มาตรฐาน (Chrome, Edge, Brave, Firefox)
